# basephpcomposer

A php Docker image with pdo_pgsql and composer. The tag corresponds to the PHP version

List of installed packages:

* zip
* unzip
* wget
* nano
* curl
* git
* composer

List of PHP extensions:

* bcmath
* mbstring
* pcntl
* intl
* zip
* opcache
* gd
* pdo
* pdo_pgsql
* pgsql

Get this image on:

* https://hub.docker.com/r/sinfallas/basephpcomposer
